ApplyPilot Application Assistant 3.1 for Google Chrome on macOS

Install
1. Double-click the ZIP file to unzip it.
2. Open Chrome and visit chrome://extensions.
3. Turn on Developer mode.
4. If an older ApplyPilot Assistant is listed, click Remove.
5. Click Load unpacked and choose the unzipped ApplyPilot folder.
6. Open your ApplyPilot dashboard. The Extension page should say "Connected".

Send the jobs you approved
1. In ApplyPilot, open Applications and look over "Ready to send".
2. Untick anything you don't want, then tap Approve & send.
3. A runner window opens and counts down from 10 seconds. Press Pause if
   you want to look first.
4. The runner opens each job's own application form, attaches that job's
   tailored resume, fills answers from your profile and checks the form
   twice.
5. On each site, you click Submit yourself until 3 of your own submissions
   there are confirmed. After that you can let ApplyPilot click Submit on
   that site in the dashboard's Extension settings.
6. Results show up in the dashboard. Keep the runner window open while it
   sends.

What it never does
- It submits only jobs you approved, once each, and only after ApplyPilot
  confirms the approval right before Submit.
- It stops and leaves the tab open, already filled, for CAPTCHAs, sign-ins
  or new accounts, passwords, legal certifications, required demographic
  and other sensitive questions, multi-page forms, and any required
  question it has no approved answer for.
- It never answers a demographic question and never solves a CAPTCHA.
  Optional demographic and other sensitive questions are left blank and
  never touched, and a page whose only CAPTCHA is an invisible background
  check can still be sent; any visible challenge stops it. You can turn
  either of these off in the dashboard's Extension settings.
- It clicks Submit at most once per job and never retries. If it can't see a
  confirmation, the dashboard asks you whether it went through.
- Press Stop in the runner, the dashboard or the popup to stop before the
  next job.

Use one Chrome profile for ApplyPilot, so its record of what was submitted
stays in one place.

Manual assistant (any site)
The popup still works on its own: import your profile JSON and a resume,
open an application, then click Run application assistant. It fills
approved blank fields and highlights questions that need you. The popup
never clicks Submit. "Save form snapshot" saves the form's structure, with
no answers, to help calibrate ApplyPilot on a new site.
